\chapter{METHODS}
\label{chap:methods}
This chapter describes the computational workflow used to retrieve, process and analyse multi-omics data for \gls{lusc} molecular subtype classification and biological interpretation. The pipeline comprises five stages: data acquisition and cohort assembly (Section~\ref{sec:data_acquisition_method}), modality-specific preprocessing (Section~\ref{sec:omics_preprocessing_method}), in silico characterisation of subtypes (Section~\ref{sec:in_silico_char_method}), dimensionality analysis and subtype separability assessment (Section~\ref{sec:dataset_sep_method}), supervised classification (Section~\ref{sec:classification_method}), and interpretability analysis (Section~\ref{sec:interpretability_method}).

Matched omics data for the \gls{tcga}-\gls{lusc} cohort were retrieved through the UCSC Xena Platform \parencite{Goldman2020}, which hosts processed \gls{tcga} data harmonised from original \gls{tcga} releases. Following datasets were retrieved: (i) gene expression by \gls{rnaseq} (IlluminaHiSeq RNASeqV2, log\textsubscript{2}(\gls{rsem}$+1$)-normalised); (ii) \gls{dna} methylation (HumanMethylation450 Illumina Infinium array, Level 3 beta values); (iii) miRNA expression (IlluminaGA miRNASeq, log\textsubscript{2}(RPM$+1$)); (iv) copy number variation (GISTIC2 all-thresholded calls, integer scale $\{-2, -1, 0, 1, 2\}$); and (v) \gls{rppa} (\gls{mdacc}, normalised protein abundance).

Molecular subtype labels (classical, secretory, basal, primitive) were derived from the original \gls{tcga} \gls{lusc} characterisation studies \parencite{Wilkerson2010, Hammerman2012}. Sample identifiers in each omics matrix were harmonised to the 12-character \gls{tcga} patient barcode format by trimming the sample and vial suffix (e.g., \texttt{TCGA-18-3406-01} $\to$ \texttt{TCGA-18-3406}). Where multiple samples from same patient were present following trimming (due to technical replicates or multiple tumour regions), first occurrence was retained, consistent with standard \gls{tcga} data processing practice. Only samples with both available omics data and a matching subtype label were retained.

\section{Omics Preprocessing}
\label{sec:omics_preprocessing_method}

Preprocessing was performed separately for each modality (labeled cohort only) to preserve the native scale and biological specific to respective platforms.

\subsection{Gene Expression}
\gls{rsem}-normalised read counts were provided in $\log_2(x+1)$-transformed form and required no additional normalisation. Genes with median $\log_2$ expression below 1.0 across all samples were removed as unexpressed. The 2,000 most variable genes were then selected by \gls{mad} filtering, which is preferred over standard deviation filtering due to the former's robustness to outliers.

\subsection{\gls{dna} Methylation}
Level 3 beta values, representing the ratio of methylated to total probe intensity and ranging on the interval $[0,1]$, were used directly without transformation. Probes missing in more than 20\% of samples were removed, and remaining missing values were imputed using the per-probe median across the labeled cohort. Probes with standard deviation below 0.05 were removed as near-invariant. This threshold is lower than the 0.01 threshold applied for count-based modalities to account for the bounded $[0, 1]$ scale of beta values, which inherently compresses absolute variability. The top 2,000 most variable probes were retained by \gls{mad}. For downstream gene-level interpretation, \gls{cpg} probe identifiers were mapped to gene symbols using Illumina HumanMethylation450 annotation; probes beginning with ``rs'' were treated as SNP probes and excluded from methylation-specific biological interpretation.

\subsection{\gls{mirna} Expression}
$\log_2(\mathrm{RPM}+1)$-transformed \gls{mirna} expression values were used without further normalisation. Missing values in this data type indicate zero reads (RPM = 0), and were therefore assigned a value of zero rather than imputed, preserving the biological interpretation of non-detection. \gls{mirna}s missing in more than 50\% of samples were removed. This permissive threshold was applied to account for tissue-specific and context-dependent expression of miRNAs where absence is frequently biological rather than technical. Low-expression filtering (median $\log_2(\mathrm{RPM}+1) < 1.0$) was then applied 200 most variable mature \gls{mirna}s were retained by \gls{mad} filtering.

\subsection{Copy Number Variation}
GISTIC2-thresholded discrete copy number values (integer scale: $-2, -1, 0, 1, 2$) were used directly. No normalisation was applied because the data encode categorical copy number states. Zero-variance genes across all samples were checked and removed (none were found). The top 2,000 most variable genes were retained by \gls{mad}.

\subsection{RPPA}
Normalised RPPA protein abundance values were used directly. Antibodies missing in more than 20\% of samples were removed. Remaining missing values, reflecting sparse antibody-level quantification failures, were imputed using the per-antibody median. No \gls{mad} filtering was applied as the post-imputation feature count (n=238) was already appropriate for the available sample size.

\section{In silico Characterisation of LUSC Subtypes}
\label{sec:in_silico_char_method}

Prior to supervised classification, the four \gls{lusc} molecular subtypes were characterised across three independent biological axes to establish the clinical relevance and biological non-redundancy of the classification target.

\subsection{Clinical Survival Analysis}
\label{sec:clinical_method}

Overall survival (\gls{os}) and progression-free interval (\gls{pfi}) were retrieved from the \gls{tcga} Clinical Data Resource, which provides curated endpoint definitions harmonised across \gls{tcga} cohorts. \gls{pfi} was designated as the primary endpoint for \gls{lusc} according to the recommendations of the \gls{tcga} Clinical Data Resource, which identifies \gls{pfi} as a more reliable surrogate for disease progression than \gls{os} in \gls{lusc} \parencite{Liu2018integrated}. Kaplan-Meier survival curves were estimated separately for each molecular subtype, and Brookmeyer-Crowley method was used to compute 95\% confidence intervals for median survival. Global log-rank tests were applied to test the null hypothesis of no difference in survival across the four subtypes. Cox proportional hazards regression was performed with the classical subtype as the reference category; hazard ratios and their 95\% confidence intervals are reported. Proportional hazards assumption was assessed using scaled Schoenfeld residuals implemented via \texttt{cox.zph}. 

All survival analyses were performed using \texttt{survival} and \texttt{survminer} packages.

\subsection{Immune Microenvironment Characterisation}
\label{sec:tme_method}

Tumour immune microenvironment composition was estimated from bulk gene expression data using two complementary deconvolution methods, following the method selection benchmarking of Sturm \textit{et al.} \parencite{Sturm2019}.


EPIC \parencite{Racle2017} was used for absolute cell-fraction estimation. EPIC deconvolves bulk expression data into cell-type-specific fractions using a non-negative least squares approach with reference gene expression profiles, yielding estimates for \gls{cd4} T cells, \gls{cd8} T cells, B cells, NK cells, macrophages, \gls{caf}s, endothelial cells, and an uncharacterised remainder (\textit{otherCells}).
 
xCell \parencite{Aran2017-xcell} was used as an independent method to derive gene set enrichment-based scores for a broader panel of immune and stromal cell types. xCell scores represent relative enrichment and are not directly comparable across cell types or to EPIC fractions; and were used to characterise cell types not covered by EPIC.
 
Differences in cell-type fractions or enrichment scores across the four molecular subtypes were assessed using the Kruskal-Wallis test, with Benjamini-Hochberg correction for multiple comparisons applied across all tested cell types. 

Analyses were performed using \texttt{EPIC} and \texttt{xCell} packages.

\subsection{Somatic Mutation Characterisation}
\label{subsec:somatic_mutation_method}
 
Somatic mutation data for \gls{tcga}-\gls{lusc} were retrieved in \gls{maf} format from the \gls{tcga} data portal and analysed using the \texttt{maftools} package \parencite{Mayakonda2018maftools}. A curated panel of 11 \gls{lusc} driver genes was constructed based on recurrently altered genes reported in the original \gls{tcga} \gls{lusc} characterisation \parencite{Hammerman2012} and established squamous lineage markers: \textit{TP53}, \textit{NFE2L2}, \textit{KEAP1}, \textit{RB1}, \textit{PTEN}, \textit{CDKN2A}, \textit{PIK3CA}, \textit{SOX2}, \textit{FGFR1}, \textit{TGM1}, and \textit{KRT75}. Alteration frequencies were computed across all samples with available mutation data and visualised as an oncoprint annotated by molecular subtype. Tumour mutational burden was computed as the total number of non-synonymous somatic mutations per sample. Differences in \gls{tmb} across subtypes were assessed using Kruskal-Wallis test.


\section{Dimensionality Structure and Subtype Separability}
\label{sec:dataset_sep_method}
Principal component analysis (PCA) was performed on each omics modality separately to characterise the geometric separability of the subtypes within each feature space. StandardScaler normalisation was applied to each modality, and minimum number of principal components explaining $\geq$ 80\% of cumulative variance was determined.

Geometric separability of subtypes was quantified using two complementary measures. The silhouette score was computed on the 80\%-variance PCA subspace, providing a sample-level measure of cluster cohesion and separation ranging from -1 (misassigned) to +1 (well-separated). Per-subtype mean silhouette scores were computed to identify subtypes with differential cluster membership. PERMANOVA with 999 permutations was applied to the same PCA subspace to test the null hypothesis that subtype group centroids are statistically indistinguishable from permuted label assignments; (pseudo-F statistic; permutation p-value). PCA projections were visualised on PC1 and PC2 with 95\% confidence ellipses (n\_std = 2.0) and subtype centroids.


\section{Machine Learning Classification}
\label{sec:ml_classification_method}

Five classifiers- logistic regression (\gls{lr}), elastic net penalised logistic regression (\gls{en}), support vector machine (\gls{svm}), random forest (\gls{rf}), and XGBoost (\gls{xgb}) were evaluated on each omics modality. 

\subsection{Feature Scaling}
 
Linear and margin-based classifiers (\gls{lr}, \gls{en}, \gls{svm}) were trained on \texttt{StandardScaler}-normalised features. The scaler was fitted on the training portion of each outer fold and applied to both training and validation portions, preventing data leakage from the validation set into the normalisation parameters. Tree-based classifiers (\gls{rf}, \gls{xgb}) are invariant to monotone feature transformations and didn't require scaling.

\subsection{Classifiers}
All classifiers were implemented in Python using \texttt{scikit-learn} \parencite{Pedregosa2011} for \gls{lr}, \gls{en}, \gls{svm}, and \gls{rf}, and the \texttt{xgboost} library \parencite{Chen2016} for \gls{xgb}. All experiments used \texttt{random\_state = 42} for reproducibility.

\gls{lr} was fitted with L2 regularisation (\texttt{solver = lbfgs}; \texttt{max\_iter = 5000}). \gls{en} combines L1 and L2 penalties via the \texttt{saga} solver, with the regularisation strength ($C$) and mixing parameter (\texttt{l1\_ratio}) optimised by nested cross-validation (see Section~\ref{subsec:cv_method}). \gls{svm} was evaluated with linear and radial basis function (\gls{rbf}) kernels; \texttt{decision\_function\_shape = ovr} was used to implement one-versus-rest multiclass decomposition. \gls{rf} was configured with \texttt{class\_weight = `balanced'} to address class imbalance. \gls{xgb} used the \texttt{multi:softmax} objective with four output classes; class imbalance was addressed by computing per-class sample weights inversely proportional to class frequency and passing these as \texttt{sample\_weight} to the \texttt{fit} call, as \gls{xgb} does not support \texttt{class\_weight} parameter natively.


\subsection{Cross-Validation and Hyperparameter Selection}
\label{subsec:cv_method}
 
Model evaluation was performed using stratified 5-fold cross-validation (\texttt{sklearn.model\_selection.StratifiedKFold}; \texttt{shuffle = True}; \texttt{random\_state = 42}), to ensure proportional representation of each subtype in every fold. No separate held-out test set was used as a hold-out split would further reduce the training set and likely degrade model performance and increase fold-level variance because per-modality cohort sizes ranged from 76 to 178 samples. Pooled out-of-fold predictions across the five validation folds were used to compute confusion matrices and per-subtype classification reports.
 
Hyperparameter selection was performed using nested inner 3-fold cross-validation applied exclusively to the training portion of each outer fold. The selection criterion was macro-averaged F1 score. Hyperparameter search spaces for each classifier are summarised in Appendix~\ref{app:hyperparam}. 


\subsection{Evaluation Metrics}
 
Classification performance is reported as mean $\pm$ standard deviation of accuracy and macro-averaged F1 score across the five outer folds. Macro F1 was chosen as the primary metric because it assigns equal weight to each of the four subtype classes, penalising models that achieve high overall accuracy by predicting frequent classes (classical, $n = 29$--$65$) at the expense of rare classes (primitive, $n = 11$--$27$). Per-subtype precision, recall, and F1 were computed from pooled out-of-fold predictions for the best-performing model per modality (selected by mean macro F1 across folds).


\subsection{Statistical Comparison of Classifiers}
 
Differences in macro F1 across the five classifiers within each modality were assessed using the Friedman test, a non-parametric test for repeated measures applied to the per-fold F1 scores (five observations per classifier). Where the Friedman test was significant ($p < 0.05$), Nemenyi post-hoc pairwise comparisons were performed using the \texttt{scikit-posthocs} library, with Bonferroni-Holm correction for multiple comparisons. Pairwise modality comparisons were
assessed using the Wilcoxon signed-rank test applied to per-fold macro F1 scores. Given that $n = 5$ folds yields a minimum achievable $p$-value of 0.0625 for the Wilcoxon test, effect sizes ($r = Z / \sqrt{N}$) are reported alongside $p$-values as the primary indicator of practical significance.


\section{Interpretability Analysis}
\label{sec:interpretability_method}

\subsection{Per-subtype SHAP Feature Importance}
\label{subsec:per_subtype_shap}

To characterise the gene-level signals driving prediction for each individual subtype, class-specific out-of-fold \gls{shap} values \parencite{Lundberg2017} were computed for gene expression, miRNA, and RPPA. CNV was excluded because of near-chance classification performance (macro F1 = 0.366; Section~\ref{subsec:omics_perf}).

For a given subtype $k$, signed SHAP contributions to the $k$-class model output were computed for all held-out samples whose \emph{true label} is subtype $k$, including samples that were misclassified (to prevent selection bias). The exact linear SHAP value for class $c$, feature $j$, and held-out sample $i$ is:
\[
\phi_{c,j}(i) = \hat{\theta}_{c,j} \cdot \bigl(x^{\text{scaled}}_{i,j} - \bar{x}^{\text{train}}_{j}\bigr)
\]
where $\hat{\theta}_{c,j}$ is the fitted coefficient for class $c$ and feature $j$, and $\bar{x}^{\text{train}}_{j}$ is the training-fold empirical mean. Additivity was verified per fold (maximum reconstruction error $< 10^{-8}$). Mean signed SHAP values across held-out samples with true label $k$ summarise the average contribution of each feature to the model's $k$-class log-odds. Per-subtype fold stability was quantified as the mean pairwise Jaccard similarity of the top-20 feature rankings across all $\binom{5}{2} = 10$ fold pairs, computed separately for each subtype. Since random Jaccard for top-20 features from 2,000 candidates is approximately $20/2,000 = 0.01$, observed values substantially above this baseline indicate stability above random. Results were visualised as signed bar charts (mean contribution per feature) and beeswarm plots (per-sample contributions colored by relative feature value within subtype).
